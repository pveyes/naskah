Tulis kode di kotak Naskah, lalu lihat hasilnya di Keluaran. Semuanya langsung jalan di sini. Baru mulai? Belajar Naskah langkah demi langkah.

NaskahArtinya

pilih x { kalau 1 { } lain { } }Memilih satu dari beberapa kemungkinan.
selama x < 10 { }Mengulang selama syaratnya masih benar.
ulang { }Mengulang terus sampai ada berhenti.
untuk i dari 1 sampai 9 { }Mengulang dengan hitungan, dari 1 sampai 9.
untuk setiap x dalam daftar { }Mengulang untuk setiap isi daftar.
